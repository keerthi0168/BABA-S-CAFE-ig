# Baba Cake Shop

A small static bakery landing page for Baba Cake Shop in Cidco, Chhatrapati Sambhajinagar.

## Live URL

https://baba-s-cafe-ig-b3qp-iz5u1id1t-keerthi0168s-projects.vercel.app/

## Preview locally

Open `title.html` directly in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then visit:

http://localhost:8000

## Deployment

This project is deployed on Vercel as a static storefront.

## Features

- Bakery landing page with hero section
- Menu highlights and customer trust section
- Responsive design for mobile and desktop
- WhatsApp order CTA
- Lightbox gallery and smooth scrolling interactions
