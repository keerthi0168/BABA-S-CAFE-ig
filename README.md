# Baba Cake Shop

A small static bakery landing page for Baba Cake Shop in Cidco, Chhatrapati Sambhajinagar.

## Live URL

https://keerthi0168.github.io/BABA-S-CAFE-ig/

## Preview locally

Open `title.html` directly in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then visit:

http://localhost:8000

## Deployment

This project is configured for GitHub Pages deployment using a static workflow in `.github/workflows/deploy-pages.yml`.

## Features

- Bakery landing page with hero section
- Menu highlights and customer trust section
- Responsive design for mobile and desktop
- WhatsApp order CTA
- Lightbox gallery and smooth scrolling interactions
